De app staat er wel, maar wordt nog niet gepubliceerd

GitHub publiceert nu de repo-root in plaats van de map app/. Dat komt doordat de Pages-bron nog op Deploy from a branch staat.

Eenmalig goedzetten: ga naar Settings → Pages en kies bij Source de optie GitHub Actions. Draai daarna de workflow Testen en publiceren opnieuw, of push iets kleins.

Waarom dit uitmaakt: bij een branch-bron draait GitHub bij elke push ook een eigen Jekyll-build. Die is later klaar dan de workflow en overschrijft de publicatie, dus je zou steeds de verkeerde inhoud zien.
